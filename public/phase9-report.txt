3. VERIFIED FEATURES & FUNCTIONALITY
--------------------------------------------------------------------------------
1. Core Expense Management:
   - Expense Creation: Unique ID generated (`uid()`), active group assigned (`pid: cur`),
     dirty flag tagged (`_d: 1`), and stored immediately in local state.
   - Expense Editing: In-place record update by ID; preserves creation timestamp and
     updates dirty flag without generating duplicate entries.
   - Expense Deletion: Soft deletion via tombstone (`deleted = 1`); immediately excluded
     from active lists, dashboard, and reports with reversible 1-click Undo toast.
   - Search & Filter: Case-insensitive query against description, note, and amount;
     category tree matching; month prefix matching; exact date matching; minimum amount.

2. Groups and Categories:
   - Group Safeguard: `delParent()` checks active groups: `if (active.length < 2) return toast(...)`.
     The user is strictly prevented from deleting their only remaining group.
   - Hierarchical Categories: Supports nested parent-child trees (e.g. Education › Exam Fee).
   - Recursive Deletion: Deleting a parent category automatically marks all descendants
     deleted and strips deleted category references from existing expenses.

3. Dashboard and Reports:
   - Period Summaries: Accurate calculations for "This Week", "This Month", "This Year",
     transaction count, daily average, and largest single expense.
   - Month-over-Month Comparison: Percentage difference against preceding month's total.
   - Category Breakdown: Conic-gradient donut chart and bar charts with accurate sums.
   - Reports: Dynamic modes (All Time, Year, Month, Week) with recursive category tree
     aggregation (`ctree`) and CSV/Print exports.

4. Budget & Financial Features:
   - Monthly Budget: Set and stored per active group (`S.budget[cur]`).
   - Progress Indicators: Visual progress bar with color shifts (teal under 80%, yellow
     under 100%, red when exceeded).
   - Accurate Balance: Real-time calculation of remaining monthly budget or exceeded amount.
   - Backup & Restore: Full JSON export and strict schema-validated JSON import.

5. Data Integrity & Usability:
   - Storage Resilience: Safe persistence with QuotaExceededError warning banner.
   - Offline Queuing: Offline expenses retain dirty flag (`_d = 1`) and sync cleanly.
   - Bengali Localization: Formatted with Bengali month names, standard currency symbol
     ('৳' or custom), and Indian comma grouping.
