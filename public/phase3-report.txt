3. IMPORTANT CHANGES MADE
--------------------------------------------------------------------------------
A. Centralized API Base URL Resolver:
   - Evaluates platform environment via `isNativePlatform()`.
   - On Web (cPanel / browser): Deterministically defaults to same-origin `'api.php'`.
   - On Capacitor Native APK: Reads from `window.KHOROCH_API_URL` or `kh_api_url`.
   - Fail-Fast Native Safety: Throws descriptive `API_URL_NOT_CONFIGURED` if an
     unconfigured placeholder is detected on native platforms, preventing silent
     degradation to invalid relative URLs.

B. Immediate Persistence & Quota Safety:
   - Zero Debounce: Transaction mutations (Add, Edit, Delete, Duplicate) write
     synchronously and immediately to `localStorage` via `persist()`.
   - Quota Guard: Traps `QuotaExceededError` and `NS_ERROR_DOM_QUOTA_REACHED`.
     Displays a non-intrusive, actionable warning toast alert to notify the user.

C. Hardware Back Button Hook:
   - Implemented `handleHardwareBack()` with strict priority resolution:
     * Priority 1: Close active `#dg` confirmation/prompt dialog.
     * Priority 2: Close active `#md` expense entry bottom sheet.
     * Priority 3: Close active `#pk` item picker modal.
     * Priority 4: Return to Home tab (`'d'`) if on another tab.
     * Priority 5: Allow native app exit if already on Home tab.
   - Registered Capacitor App plugin listener `App.addListener('backButton')`.
