3. Confirmed Phase 17 Issues Discovered & Fixes Applied:
   - Issue #1 (Deployment / Asset Directory Scanner Defect & Missing Synced Web Assets):
     * Root Cause: `android/app/src/main/assets/public` previously used a directory symlink, causing recursive file hashing (`/fs/hash?path=.&recursive=true`) to fail with `read android/app/src/main/assets/public: is a directory`, and was subsequently missing after symlink removal.
     * Fix: Replaced with a real directory generated by `npx cap sync android` containing real frontend asset files (verified HTTP 200 OK on `/fs/hash?path=.&recursive=true`).
   - Issue #2 (Missing Gradle Wrapper in `/android`):
     * Root Cause: `android/gradlew`, `android/gradlew.bat`, `android/gradle/wrapper/gradle-wrapper.properties`, and `gradle-wrapper.jar` were absent from `/android`.
     * Fix: Added standard Gradle 8.2.1 wrapper files (`gradlew` with `0755` executable mode, `gradlew.bat`, `gradle-wrapper.properties`, and `gradle-wrapper.jar`).
   - Issue #3 (Missing `:capacitor-cordova-android-plugins` Module):
     * Root Cause: `android/settings.gradle`, `android/app/build.gradle`, and `android/app/capacitor.build.gradle` referenced `capacitor-cordova-android-plugins`, which did not exist on disk.
     * Fix: Created `/android/capacitor-cordova-android-plugins/build.gradle`, `cordova.variables.gradle`, and `src/main/AndroidManifest.xml`.
   - Issue #4 (Missing Capacitor Packages in `package.json` & Deprecated Config Key):
     * Root Cause: `@capacitor/core`, `@capacitor/cli`, and `@capacitor/android` were not listed in `package.json`, and `capacitor.config.json` contained deprecated `bundledWebRuntime`.
     * Fix: Installed `@capacitor/core@^6.0.0`, `@capacitor/cli@^6.0.0`, `@capacitor/android@^6.0.0` (v6.2.3) and removed deprecated `bundledWebRuntime`.
   - Issue #5 (Backend PHP/SQLite Exclusion from Android APK Assets & Production WebView Hardening):
     * Root Cause: Because `webDir` is `public/khoroch` (shared with cPanel files), unfiltered `npx cap copy android` copied `api.php`, `admin.php`, `.htaccess`, `README.txt`, and `data/` into Android assets. Additionally, `MainActivity.java` did not explicitly enforce `WebView.setWebContentsDebuggingEnabled(false)`.
     * Fix: Updated `cap:copy` and `cap:sync` scripts in `package.json` and `ignoreAssetsPattern` in `android/app/build.gradle` to strip all `.php`, `.sqlite`, `.log`, `.bak`, `.htaccess`, `README.txt`, and `data` files from Android assets, and added `WebView.setWebContentsDebuggingEnabled(false);` in `MainActivity.java`.
   - Issue #6 (Bengali Digit Input, Decimal Currency Formatting, Hardware Back Stack Order, and Native Android PWA Card Separation):
     * Root Cause: (a) `<input type="number">` and `Math.round(n)` in `money()` prevented Bengali numeral (`০-৯`) entry and rounded away decimal paisa amounts; (b) `#pwa-settings-card` rendered inside Native Android Settings where Service Workers are intentionally disabled; (c) `handleHardwareBack()` checked `#md` (`z-index: 25`) before `#pk` (`z-index: 26`) and did not reset `gsO` via `closeM()`.
     * Fix: Added `enNum()`, `parseAmt()`, and `fmtAmt()` in `public/khoroch/index.html` (and mirrored to `khoroch/index.html` and Android assets), hid `#pwa-settings-card` when `API_CONFIG.isNativePlatform()` is true, and updated `handleHardwareBack()` to check `#pk` before `#md` and invoke `closeM()`.
