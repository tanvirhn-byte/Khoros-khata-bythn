   - Preserved the exact Khoroch er Khata branding (`T` logo, Bengali typography, dark slate/teal palette).

C. Service Worker & Cache Management (`public/khoroch/sw.js` & `khoroch/sw.js`)
   - Upgraded cache version to `CACHE_NAME = 'kh-pwa-v12'`.
   - Precaches all 8 essential application shell assets (`./`, `index.html`, `manifest.json`, `icon-192.png`, `icon-512.png`, `icon-maskable-192.png`, `icon-maskable-512.png`, `apple-touch-icon.png`) using `Promise.allSettled` so a single optional asset failure cannot abort Service Worker installation.
   - `activate` lifecycle handler deletes outdated `kh-*` and `khoroch-*` CacheStorage buckets while leaving `localStorage` (`kh`, `kh_t`, `kh_cfg`, `kh_ack_notices`, etc.) untouched.
   - `fetch` handler strictly bypasses:
     * All non-`GET` requests (`POST`, etc.)
     * Any URL ending in `api.php` or `admin.php`
     * Any URL with query parameter `?a=` or path `/api/`
     * Any request carrying an `Authorization` header
   - Navigation requests (`req.mode === 'navigate'`) use Network-First with seamless fallback to cached `index.html` or `./` when offline.
   - Static shell assets use Cache-First with background network refresh and safe image fallback.

D. Installation Experience & Standalone Mode (`public/khoroch/index.html` & `khoroch/index.html`)
   - Added `beforeinstallprompt` and `appinstalled` event listeners.
   - Added `isStandaloneMode()` detector checking `display-mode: standalone`, `display-mode: fullscreen`, `navigator.standalone === true`, `android-app://` referrer, and `API_CONFIG.isNativePlatform()`.
   - Added a header install chip (`#pwa-inst-btn`, `"📲 ইনস্টল"`) when `beforeinstallprompt` is available and the app is not yet in standalone mode.
   - Added a dedicated **"অ্যাপ ইনস্টল ও PWA"** card (`#pwa-settings-card`) in Settings (`vb()`):
     * Displays active installation state (`Standalone App Mode` vs browser mode).
     * Triggers native install prompt (`triggerPwaInstall()`) when supported, or opens a guided Bengali modal (`showPwaInstallGuide()`) with step-by-step instructions for Android Chrome (`⋮ → Install app / Add to Home screen`) and iOS Safari (`Share ⇪ → Add to Home Screen`).
     * Suppresses redundant install buttons once running in standalone mode.

E. Safe Application Update Lifecycle (`public/khoroch/index.html` & `public/khoroch/sw.js`)
   - Removed immediate forced takeover during active sessions; instead, when a new Service Worker reaches `installed` state while a controller is active, the non-intrusive update bar (`#pwa-upd-bar`, `"✨ অ্যাপের নতুন সংস্করণ প্রস্তুত আছে"`) appears with `"আপডেট করুন"` (`applySwUpdate()`) and `"পরে"` (`dismissSwUpdate()`).
   - Tapping `"আপডেট করুন"` posts `{ type: 'SKIP_WAITING' }` to the waiting worker.
   - `controllerchange` listener uses a single-shot `swReloading` guard and checks `if (isUserInputActive() || busy) return;` so it never causes an infinite reload loop and never interrupts active expense entry or an in-progress sync.
   - Native Capacitor Android environments are explicitly excluded from Service Worker registration (`!API_CONFIG.isNativePlatform()`).
